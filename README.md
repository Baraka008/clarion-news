# Clarion Feature

A production-ready modern news platform built with Next.js, Tailwind CSS, Firebase, and Gemini AI.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Create `.env.local` with Firebase and Gemini keys.
3. Run dev server:
   ```bash
   npm run dev
   ```

## Architecture

- Next.js App Router
- Firebase Auth / Firestore / Storage
- Gemini AI integration via API route
- Admin dashboard for publishing and moderation
